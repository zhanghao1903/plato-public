# Public Visualizations

This directory contains standalone public-safe HTML visualizations and their
source data.

| File | Purpose |
|---|---|
| `plato-architecture-overview.html` | Standalone Product 1.1 architecture map for external publishing. |
| `plato-architecture-overview.architecture.json` | Archify source data used to regenerate the architecture map. |
| `plato-agent-loop.html` | Standalone Agent Loop data-flow map for external publishing. |
| `plato-agent-loop.dataflow.json` | Archify source data used to regenerate the Agent Loop map. |

Do not add visualizations with private paths, local usernames, real user
content, API keys, raw diagnostics, or private repository URLs.
