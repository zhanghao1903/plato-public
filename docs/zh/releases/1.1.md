# Plato 1.1 发布说明

Plato `1.1` 是正式公开的 Product 1.1 macOS Apple Silicon 本地版本。它将
Product 1.1 的 Router-first Conversation、Activity、Audit、diagnostics 和
workspace inspection 基础能力从 beta 推进到稳定公开通道。

这个版本仍然是未签名、未公证的本地发行版，适合本地评估和评审，不是应用商店级分发。

## 相比 Product 1.0 有什么变化

Product 1.0 的公开基线是 `0.1.0`：它验证了 task-first 基础循环，也就是把目标转成可见计划、执行本地任务，并通过 Audit 检查结果。

Product 1.1 将主循环升级为 Router-first conversation 和 evidence workflow：

```text
用户输入
  -> Runtime Input Router
  -> 只读回答、ASK/confirmation 回答、指导、修订命令、归档计划查看或执行交接
  -> 持久化 Conversation / Activity
  -> Audit、diagnostics、workspace inspection 和文件证据
```

用户不需要先判断自己输入的是新计划、指导、问题、ASK 回答、任务修订还是执行请求。Plato 负责路由输入，并记录结果。

## 本版本新增能力

### Runtime Input Router

- 同一个 Main Page 输入框可以处理问题、指导、ASK 回答、confirmation 回答、plan/task 修订和 execution handoff。
- 会改变 workspace 的行为仍然通过命令执行，而不是 Router 直接写入。

### Durable Conversation And Activity

- 持久化用户输入、Router interpretation、只读回答、ASK 卡片、confirmation 流程、任务更新、命令结果和 plan archive 事件。
- Conversation 成为主要的用户可见历史界面。

### Read-Only Inquiry

- 可以回答当前 session 或 workspace 的问题，不修改文件或任务状态。
- 将 no-effect answer 和可用证据引用写入 Activity。

### ASK And Confirmation Routing

- Router 发起的问题卡片显示在 Conversation 流程中。
- 问题和用户回答都会作为 conversation 内容保存。

### Contract Revision Commands

- 计划/任务修订和指导使用 command-backed 行为。
- 区分只读回答和 execution handoff。

### Workspace Inspection

- 增加 git status、changed files、structured diff 和 file viewer 入口。
- 使用 renderer-safe 标签和 Audit evidence，让本地 workspace 修改可检查。

### Token Usage Analytics

- 增加本地 session / workspace token 使用记录和汇总基础能力。

### Precision File Tools

- 增加按行读取、搜索、hash 保护的行范围替换、append 和 changed-line evidence 基础能力。

### Archived Plan Access

- 完成或归档后的 plan 仍可从 Conversation 访问。
- 归档 plan 以接近原 active plan 的 Plan & Progress 页面展示，并提供 Audit 入口。

### Frontend Interaction Runtime

- 改进提交响应、pending row、route-return focus、overlay close-return focus 和 Conversation 滚动稳定性。
- 修复 installer smoke blocker：用户阅读历史时提交输入不应强制把 Conversation 滚到底部。

## 行为变化

- Stable 通道现在指向 Product `1.1`；`0.1.0` 作为 Product 1.0 旧基线保留。
- 输入框不再只是计划/任务文本框，而是 routed product input。
- Conversation、Activity、Audit、diagnostics 和 workspace inspection 成为主要信任界面。
- 只读问题不会创建任务，除非确实需要执行工作。
- plan/task 修改通过可审计命令完成。
- 打包流程使用显式 release version，并确保 public DMG 不包含 smoke/test 资产。

## 已知限制

- 应用未签名。
- 应用未公证。
- macOS Gatekeeper 可能阻止普通打开。
- 仅发布 macOS Apple Silicon 版本。
- 本仓库不是源码镜像。
- Web retrieval 依赖配置，应视为能力基础，不是所有用户默认可用的完整体验。
- 签名、公证、自动更新、远程执行、广泛 MCP 集成、多模态输入和 marketplace 式分发不包含在本版本内。

## 建议首次测试

1. 在测试 workspace 中打开 Plato。
2. 创建或打开一个已初始化 Git 的本地项目。
3. 先问一个关于当前 session 的小问题，确认它以只读回答显示在 Conversation 中。
4. 启动一个低风险任务，检查可见任务计划。
5. 打开 workspace inspection，查看 git status、changed file 和 diff。
6. 有 activity 后打开 Audit Page 检查证据。
7. 有 AI activity 后检查 token usage summary。
